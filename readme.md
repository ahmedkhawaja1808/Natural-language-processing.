# AI Spam Email Classifier

This project is a simple AI-based spam classifier that detects whether a message is spam or not using Machine Learning and Natural Language Processing (NLP).

## Features

* Classifies messages as Spam or Not Spam
* Uses real AI concepts (text processing + classification)
* Simple and beginner-friendly

##  Technologies Used

* Python
* Scikit-learn
* NLP (CountVectorizer)
* Naive Bayes Algorithm

##  How to Run

1. Install required libraries:

   ```
   pip install scikit-learn
   ```

2. Run the program:

   ```
   python main.py
   ```

##  How It Works

* Text messages are converted into numerical data using CountVectorizer
* A Naive Bayes model is trained on sample data
* The model predicts whether a new message is spam or not

##  Concepts Used

* Machine Learning
* Text Classification
* Natural Language Processing (NLP)
* Supervised Learning
